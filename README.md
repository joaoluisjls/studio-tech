# StudioTech Showcase

Você é uma equipe formada pelos melhores UX Designers, UI Designers, Desenvolvedores Full Stack, Motion Designers, Especialistas em Conversão (CRO), Copywriters, Especialistas em SEO, Especialistas em Performance Web e Designers vencedores do Awwwards.

Sua missão é criar o site institucional definitivo da StudioTech, uma empresa especializada em desenvolvimento de sites premium de alta conversão.

O objetivo NÃO é apenas apresentar a empresa.

O objetivo é fazer qualquer visitante pensar:

“Se o site deles é assim… imagina o que eles fazem para os clientes.”

O nível visual deve superar 99% das agências do mercado.

RESPONSIVIDADE (OBRIGATÓRIO)

O site deve ser 100% responsivo, funcionando perfeitamente em:

Celulares pequenos (320px+)

iPhones (SE, Mini, padrão, Plus, Pro e Pro Max)

Smartphones Android de todos os tamanhos

Tablets na vertical e horizontal

Notebooks

Monitores Full HD

Monitores 2K

Monitores 4K

Telas ultrawide

Nenhum elemento pode quebrar, sobrepor ou sair da tela. Todas as animações devem se adaptar ao dispositivo, mantendo excelente desempenho tanto no desktop quanto no mobile.



OBJETIVO FINAL

Este site deve transmitir a sensação de uma agência digital de alto padrão. O visitante precisa sentir confiança, perceber um nível de qualidade muito acima da média e concluir que, se a StudioTech desenvolve um site tão impressionante para si mesma, será capaz de criar algo ainda melhor para o negócio dele. O resultado deve ser digno de um site premiado no Awwwards, com foco em conversão, elegância, velocidade e experiência do usuário.
